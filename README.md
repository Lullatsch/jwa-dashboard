# JWA Leaderboard Dashboard

A static dashboard for exploring Jurassic World Alive leaderboard snapshots. It shows which creatures and teams appear most often, how creature picks are connected, and how popularity changes between snapshots.

[Open the dashboard](https://lullatsch.github.io/jwa-dashboard/)

Use the event and snapshot selectors to browse past captures. The dashboard also includes tournament rules and build details where they are available.

This is an unofficial community project and is not affiliated with Jam City, Ludia, Universal, or Jurassic World Alive.
